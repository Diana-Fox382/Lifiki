# 🖤 Lifiki — симулятор искусственной жизни

Браузерный симулятор нейроэволюции: маленькие чёрные пушистики (как чернушки из «Моего соседа Тоторо») живут в замкнутом мире, ищут зелёную еду, избегают красного яда, делятся и **эволюционируют**: у каждого есть своя нейросеть, и потомки наследуют мозг родителя с мутациями.

Написано на чистом **HTML + CSS + JavaScript**, без движков и библиотек. Сборка, сервер и установка чего-либо не нужны.

---

## 🚀 Как запустить (пошагово)

### Способ 1. Скачать ZIP (самый простой)

1. Откройте страницу репозитория на GitHub.
2. Если нужны файлы из ветки разработки, переключите ветку в выпадающем списке слева вверху (кнопка с названием ветки, например `main`).
3. Нажмите зелёную кнопку **`<> Code`**, затем **`Download ZIP`**.
4. Распакуйте архив: правый клик → «Извлечь всё…» (Windows) или двойной клик (macOS).
5. Откройте распакованную папку и **дважды кликните по `index.html`**. Игра откроется в браузере.

> Лучше всего использовать свежий **Chrome**, **Edge**, **Firefox** или **Safari**.

### Способ 2. Через Git (если он установлен)

```bash
git clone https://github.com/Diana-Fox382/Lifiki.git
cd Lifiki
```

Потом откройте `index.html` в браузере (двойной клик или перетащите файл в окно браузера).

### Способ 3. Через локальный сервер (по желанию)

Нужен, только если браузер что-то блокирует при открытии через `file://`. Если установлен Python:

```bash
cd Lifiki
python -m http.server 8000
```

Затем откройте в браузере адрес **http://localhost:8000**.

В VS Code можно поставить расширение **Live Server** и нажать «Go Live».

## 🎮 Управление

| Действие | Что происходит |
|---|---|
| **Клик / удержание мыши на пушистике** | Поглаживание: он останавливается, мурчит, из него летят сердечки, восстанавливается энергия |
| **Провести зажатой мышкой по нескольким** | Гладятся все, кого коснулись |
| **Навести курсор** | Карточка существа: поколение, возраст, энергия, сколько съел, сколько детей |
| **Пробел** или кнопка «⏸ Пауза» | Пауза / продолжить |
| **⏩ x1 / x2 / x4** | Ускорение симуляции |
| **💬 Позвать на связь** | Запустить «Сеанс связи» прямо сейчас (для проверки, не дожидаясь 10-го поколения) |

На телефоне гладить можно пальцем.

## 🧬 Как устроена симуляция

**Мир.** Весь экран; края склеены (ушёл вправо — вышел слева). Зелёная еда постепенно отрастает, красный яд восстанавливается.

**Мозг.** Нейросеть прямого распространения `5 → 8 → 2`:
- входы: угол до ближайшей еды, расстояние до неё, угол до ближайшего яда, расстояние до него, текущая энергия;
- выходы: ускорение (газ/тормоз) и поворот.

**Жизненный цикл.**
- Движение тратит энергию: чем быстрее, тем дороже.
- Съел еду — энергия восстанавливается (и короткий «пульс» `scale(1.3)`).
- Съел яд или кончилась энергия — смерть, пушистик рассыпается в сажу.
- Энергия дошла до максимума — деление с сильным вытягиванием. Потомок получает копию мозга с мутациями.

**Эволюция.** Сначала мозги случайные, и почти все быстро погибают. Если популяция падает ниже минимума, мир подселяет новых существ, обычно с мутированным мозгом рекордсмена. Примерно через **3–6 минут** появляются «умные» линии, которые целенаправленно едят и обходят яд. После этого популяция растёт, а поколения быстро увеличиваются.

**👑 Корона** висит над самым старым из живых существ, то есть над рекордсменом.

### ✨ Фишки

- **Погладить (Petting).** Клик или удержание на существе: оно останавливается и мурчит. Ядро и шерсть мелко и часто вибрируют, шерсть распушается от удовольствия, глаза щурятся «^ ^», появляется румянец, вылетают сердечки. Энергия восстанавливается: это поощрение от Создателя.
- **Сеанс связи с Создателем (Hive Mind).** Шкала «🧠 Осознанность» показывает, насколько популяция близка к среднему поколению 10. Когда порог пройден, примерно раз в минуту существа бросают еду, собираются вместе (steering behaviors: *arrive* + *separation*) и выстраиваются в **сердце**, **смайлик** или **«HI»**. Несколько секунд держат фигуру, а потом разлетаются.

### 🖤 Как нарисованы чернушки (сусуватари)

- **Ядро.** Чёрный шар с бликом и мохнатым краем. Подшёрсток заранее «запечён» в картинку, поэтому FPS он не тратит.
- **Глаза.** Большие и белые, всегда смотрят на зрителя. Зрачки плавно смещаются туда, куда существо движется. Существо моргает, а при голоде глаза становятся сонными.
- **Шерсть с физикой** (`fur.js`). 26 волосков, каждый из которых — цепочка из 3 точек на **Verlet-интеграции**. Корень приклеен к ядру, а точки живут по инерции. Пружина «памяти формы» держит волосок торчащим наружу, а ограничение длины не даёт ему растянуться. Когда существо бежит, кончики тянутся сзади.
- **Покой (idle).** Кончики волосков всё время мягко колышутся, как от ветерка: две несоразмерные синусоиды от `Date.now()`, у каждого волоска своя фаза.
- **Мурчание.** Высокочастотная вибрация ядра (около 30 Гц) и шерсти с маленькой амплитудой.
- **Дыхание** (`breathing.js`). Асимметричный цикл длиной 4,5 с через `Date.now() % 4500`:

  | Время | Фаза | Что происходит |
  |---|---|---|
  | 0–1200 мс | Вдох | ease-out: ядро становится шире и чуть ниже, корни волос раздвигаются, шерсть приподнимается |
  | 1200–1500 мс | Пауза на вдохе | задержка дыхания |
  | 1500–3200 мс | Выдох | ease-in-out: ядро «оседает», шерсть опадает |
  | 3200–4500 мс | Пауза на выдохе | полный покой |

  У каждого существа свой сдвиг фазы `breathOffset`, поэтому толпа дышит вразнобой.
- Все деформации ядра (дыхание, ходьба, деление, мурчание, еда) собираются в одну матрицу 2×2 (`Creature.computeBody`). По этой же матрице считаются корни волосков, поэтому шерсть следует за ядром.
- Шерсть и дыхание обновляются по реальному времени, так что даже на паузе чернушки продолжают дышать.

## 📁 Что за что отвечает

Скрипты подключаются в `index.html` строго по порядку: каждый следующий использует классы из предыдущих.

| Файл | Назначение |
|---|---|
| `index.html` | Страница: canvas, стеклянная панель статистики, кнопки, подключение скриптов |
| `style.css` | Оформление: glassmorphism (полупрозрачность + `backdrop-filter: blur`), кнопки, баннер, мобильная версия |
| `config.js` | **Все настройки игры** (скорость, энергия, мутации, частота сеансов связи…). Начинать эксперименты лучше отсюда |
| `utils.js` | Математические помощники: `clamp`, `lerp`, работа с углами, гауссов шум |
| `neural.js` | Класс `NeuralNetwork`: прямое распространение (`predict`), копирование, мутация |
| `particles.js` | Класс `ParticleSystem`: сердечки, искорки, сажа |
| `breathing.js` | Объект `Breathing`: асимметричный цикл дыхания (вдох → пауза → выдох → покой) |
| `fur.js` | Класс `SootFur`: физика шерсти (Verlet + пружины), ветерок, вибрация при мурчании, отрисовка волосков |
| `assets.js` | Класс `AssetManager`: загрузка `creature.png`, ядро и глаза чернушки, спрайты еды и яда, фон |
| `creature.js` | Класс `Creature`: органы чувств, мышление, движение, энергия, деление, деформации ядра, все анимации |
| `world.js` | Класс `World`: еда, яд, замкнутые края, поиск ближайшего объекта, рекорды |
| `hivemind.js` | Класс `HiveMind`: «Сеанс связи», фигуры (сердце, смайлик, HI), steering behaviors |
| `ui.js` | Класс `UI`: обновление статистики, кнопок, баннера и подсказок на странице |
| `main.js` | Класс `Simulation`: игровой цикл, ввод мыши (поглаживание), рождение и смерть, отрисовка кадра |

## 🎨 Своя картинка существа

Положите рядом с `index.html` файл **`creature.png`**, например квадратную PNG 128×128 с прозрачным фоном. Персонаж на картинке должен **смотреть вправо →**: картинка поворачивается по направлению движения. Игра подхватит её автоматически. Если файла нет, рисуется процедурная чернушка с физикой шерсти.

> В консоли браузера (F12) при этом может появиться сообщение `Failed to load resource … creature.png`. Это нормально: так AssetManager понимает, что картинки нет, и рисует пушистика сам.

## 🔧 Идеи для экспериментов

Откройте `config.js`, поменяйте числа, сохраните и обновите страницу (F5):

- `energy.food` — сделайте еду питательнее, и популяция взорвётся;
- `world.poisonPerMegapixel` — больше яда, жёстче естественный отбор;
- `brain.hidden` — больше нейронов, «умнее», но эволюция дольше;
- `comm.minAvgGeneration` и `comm.interval` — как скоро и как часто существа выходят на связь;
- `brain.mutationRate` — частота мутаций;
- раздел `soot` — внешность чернушек: число и длина волосков, упругость (`stiffness`), сила ветерка и мурчания;
- раздел `breathing` — длительность фаз дыхания и насколько сильно «раздувается» ядро.

Из консоли браузера (F12 → Console) доступен объект `lifiki`, например:

```js
lifiki.world.creatures.length          // сколько существ
lifiki.hive.start(lifiki.world, lifiki.particles, lifiki.ui)  // сеанс связи вручную
```
